# 🍞 빵들의 전쟁 (Bread Wars)

외계 「글룹 제국」의 침공에 맞서, 마법 오븐에서 구운 빵들로 지구를 지키는 2D 픽셀 타워 디펜스 웹게임입니다.
모든 그래픽(빵·외계인·성·배경)과 사운드는 JavaScript + Canvas 2D / Web Audio로 코드에서 직접 생성됩니다.

## 실행 방법

- **가장 간단한 방법:** `index.html`을 크롬/엣지에서 더블클릭해 엽니다.
- **로컬 서버로 실행:** PowerShell에서
  ```
  powershell -ExecutionPolicy Bypass -File serve.ps1
  ```
  실행 후 브라우저에서 `http://localhost:8123` 접속.

진행 상황은 브라우저의 localStorage에 자동 저장됩니다. (설정 → 데이터 초기화로 리셋)

## 조작

| 동작 | 마우스/터치 | 키보드 |
|---|---|---|
| 빵 출격 | 하단 빵 카드 클릭 | `1` ~ `7` |
| 화력 업 (코스트 회복·최대치 증가) | 「화력 업」 버튼 | `Q` |
| 오븐 대포 (전방 적 일소) | 「오븐 대포」 버튼 | `W` / `Space` |
| 일시정지 | 우측 상단 버튼 | `Esc` / `P` |

## 게임 시스템

- **시리즈 1 「밀가루 대륙 방어전」** — 20개의 전투 (10번째·20번째는 보스전)
- **전투:** 왼쪽 외계 기지에서 적이 몰려오고, 오른쪽 오븐에서 빵이 출격합니다. 적 기지를 부수면 승리, 오븐이 부서지면 패배.
  - 코스트는 기본 1초에 1씩 증가 (화력 업으로 증가량·최대치 상승), 외계인 처치 시 보너스 코스트
  - 빵마다 재투입 대기 시간 존재
  - 적 기지 체력이 줄면 증원 부대 출현, 시간이 지날수록 적의 공세가 거세짐
- **보상:** 최초 클리어 시 골드 + 밀가루 + (일부 전투) 새 빵 레시피, 재도전 시 골드만
- **재화:** 골드(강화), 밀가루(뽑기), 에너지(출격, 1분에 1 회복 · 최대 30)
- **레시피 북:** 16종의 빵 카드 (★일반 / ★★희귀 / ★★★전설). 미보유 빵은 `?` 카드
- **강화:** 골드로 레벨 업 (최대 Lv.20), **Lv.10에 진화**하면 이름·외형·능력치가 크게 변화
- **파티 구성:** 최대 7개의 빵 편성 (추천 편성 기능)
- **뽑기:** 밀가루로 상시 뽑기 (1회 100 / 10회 900, 10회는 ★★ 이상 1개 확정). 중복 레시피는 레벨 +1

## 빵 스탯

## v2 추가 사항

- **콘텐츠:** 빵 37종(일반 29 + 로봇 8), 외계인 25종(보스 6), 3개 시리즈 × 20전투 = 60전투
- **특별 뽑기 시즌 1 「메카 베이커리」:** 로봇 빵 8종 한정 (30회 안에 전설 확정)
- **별 평가:** 오븐 체력 70% 이상 ★3 / 35% 이상 ★2. 새 별마다 밀가루 보너스
- **도전 과제:** 달성 시 밀가루·골드 보상
- **대공세:** 일정 시간마다 강화된 적이 한꺼번에 몰려옴
- **속성:** 외계인은 일반 / 불(강한 공격) / 바람(밀쳐내기) / 어둠(지속 피해) / 얼음(빙결) 속성을 가짐
  - 불 1-6, 바람 1-11, 어둠 1-16, 얼음 2-6부터 등장
  - 빵마다 **저항**(피해 감소 + 상태 이상 면역)과 **특효**(피해 +75%)가 다름 — `js/data.js`의 `AFF` 표
  - 맵의 전투 정보에서 등장 속성과 내 파티의 상성을 확인, 파티 화면의 「추천 편성」은 상성을 반영
- 저장 키가 `breadwar_save_v2`로 바뀌어 이전 저장은 이어지지 않음
